# 📊 Análisis de Datos con SQL - Base de Datos Shakila

📖 Descripción del Proyecto
Este proyecto consiste en el análisis de la base de datos de un videoclub mediante consultas SQL. A lo largo del proyecto se resuelven más de 60 ejercicios prácticos enfocados en extraer métricas de negocio, comportamiento de clientes y rendimiento del inventario.

🛠️ Tecnologías y Herramientas
PostgreSQL
DBeaver

🚀 Pasos Seguidos durante el Proyecto
1. Creación del Esquema: Creación del esquema, lo cual nos permite explorar el formato de las tablas y la relación entre si. 
2. Desarrollo y Optimización de Consultas: Resolución de los ejercicios prácticos aplicando los conocimientos adquiridos en el curso.

📊 Resultados y Conclusiones
A partir de las consultas resueltas, se identificaron los siguientes hallazgos clave:

Categorías más Populares: Las categorías con mayor volumen de alquileres son 'Sports' y 'Animation'.
Categorías menos Populares: Las categorías con menor volumen de alquileres son 'Music' y 'Travel'.
Películas más alquiladas: Las películas más alquiladas son 'Bucket Brotherhood' y 'Rocketeer Mother'.
Películas menos alquiladas: Las películas menos alquiladas son 'Lolita World' y 'Blood Argonauts'.
Segmentación de Clientes: Se identificó un núcleo de clientes VIP que superan más de 30 alquileres, representando la mayor parte de la recurrencia del negocio.
Meses con más alquileres: Julio (6.709) y Agosto (5.686) fueron los meses con mayor número de alquileres. 
Meses con menos alquileres: Febrero (182) y Mayo (1.156) fueron los meses con menor número de alquileres.
Media de la duración de los alquileres: La media de duración del alquiler de las películas es de 4,9 días.
